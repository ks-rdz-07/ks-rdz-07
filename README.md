I founded **Radaz Technologies** to help businesses turn ideas into reliable, production-grade technology. One team handles the whole product: hardware firmware, cloud backends, web portals, mobile apps and the infrastructure they run on.

I lead product strategy, solution architecture and delivery, and I still work hands-on in the code.
